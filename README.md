# xQWERTILE Time Parser
xQWERTYa Time Parser is a simple C# .NET 10.0 project which provides a CLI for checking if a provided string is a valid xQWERTILE time string. 

## How to Use xQWERTILE Time Parser
1. Download the [latest releases's](../../releases) `.zip`.
2. Extract the contents into a directory of your choice.
3. Open `input.txt` and enter your time string. 
4. Open the program and it will check your string.
    - you can press enter in the program to check the string again or check a new string (if you have changed the contents of `input.txt`).
